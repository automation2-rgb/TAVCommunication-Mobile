# Keyboard shortcuts and composer keys

Global and context-specific shortcuts on production `master`.

---

## Global

| Shortcut | Action |
|----------|--------|
| **Ctrl/⌘ + K** | Open search modal (from inbox; also closes when open) |
| **Esc** | Close search modal, lightbox, drawers, many modals |

---

## Inbox composer

| Key | Action |
|-----|--------|
| **Shift + Enter** | Send message |
| **Enter** | New line |
| **/** or snippets icon | Open slash menu / snippets picker |

Helper text under composer documents these behaviors.

---

## Search modal

| Key | Action |
|-----|--------|
| **Esc** | Close |
| **Ctrl/⌘ + K** | Toggle close |
| Arrow keys | Navigate results (when implemented in modal focus) |

---

## Thread list / conversation (mobile)

| Action | Detail |
|--------|--------|
| Back chevron | Return from thread to list |

---

## Help page documented shortcuts

**Route:** `/help` — lists Ctrl/⌘+K, Enter, Esc for general workspace use.

---

## Accessibility

Global button `:active` scale feedback in `globals.css`.  
`prefers-reduced-motion` disables pane/drawer swish animations.
